# Квинта · 1.13

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, метроном, аккорды и композиции с репетицией. На iPhone: Safari → Поделиться → На экран Домой. Избранное хранится на устройстве каждого человека.

## Обновление 1.13

Добавлена статистика использования: первые замеченные запуски с иконки (оценка установок), активные копии, визиты, копирования и системная отправка ссылок, открытия и сохранения полученных наборов. Отдельный кабинет владельца защищён входом ChatGPT и приватным доступом Sites. Периоды сегодня, 7 и 30 дней, всё время; фильтр адреса приложения и график по дням.

[Кабинет владельца](https://kvinta-private-statistics.sappy-mule-8607.chatgpt.site/) — доступен только владельцу.

В статистику не передаются имена, содержимое наборов, сами ссылки и звук с микрофона. Случайный идентификатор различает копии приложения. Данные отправляются в собственный коллектор Sites; GitHub Pages остаётся статическим. В настройках можно отключить будущую отправку. При отсутствии сети музыка работает, очередь событий ограничена 7 днями и 500 событиями, повторы не удваивают счётчики.

Установки и активные копии не равны точному числу людей. Системная отправка не подтверждает доставку. История начинается с обновления.

192 проверки приложения и 2 проверки защиты кабинета. Браузером проверены фильтры, пустой отчёт, копирование, открытие, сохранение и отключение статистики. Физический iPhone удалённо не проверялся.

## Исходники

В kvinta-github-source.zip: статический dist, тесты, исходники коллектора, схема и миграции без секретов. Запуск: node server.mjs. Проверки: node tests/all.test.mjs. Нужен современный Node 22+. GitHub Actions проверяет приложение и публикует только статические файлы dist.
