# Квинта · 1.8

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, аккорды, метроном и композиции с репетицией. После первой загрузки работает без интернета. На iPhone: Safari → Поделиться → На экран Домой.

## Обновление 1.8

- Порядок частей в репетиции с повторениями: куплет → куплет → припев → куплет → припев. Настраивается кнопкой «Порядок», сохраняется в наборе и передаётся по ссылке. Аккорды одной части редактируются один раз.
- Отдельные вкладки Редактор/Репетиция. Нижняя строка: По кругу, Порядок, настройки, Старт. Звук аккордов и мерцание — в настройках репетиции, без эмодзи.
- Компактные карточки избранного без размера и лишних кнопок. Удаление наборов и тональностей только свайпом влево, для набора есть восстановление.
- Подсказки листаются свайпами в обе стороны. Окно постоянной высоты, длинный текст прокручивается внутри. Напоминание об отключении только на первой карточке; заголовки юмора и финальные фразы чередуются. До семи новых карточек за запуск.
- Ручной переворот экрана на 180° и автопереворот по датчикам в настройках. На iPhone пользователь включает его с разрешением датчиков; действует до закрытия приложения. Держать телефон обычно при включении. Системную анимацию iOS веб-приложение не отключает.
- Тюнер: исправлена воспроизводимая на тестовом сигнале ошибка октавы при преобладании второго обертона, снижен порог тихого звука и увеличено окно анализа. Неясная оценка не подтверждает настройку и не советует натягивать струну. Индикатор уровня согласован с распознаванием тихого сигнала.

156 автоматических проверок. В браузере проверены свайпы, одинаковая высота подсказок, сохранение и импорт порядка, запуск репетиции и переход между частями, экраны 390×763 и 360×640. Настройку реальной неподключённой электрогитары через микрофон iPhone и выдачу разрешения датчиков необходимо проверить на устройстве.

## Исходники

Архив kvinta-github-source.zip: dist, tests, README, package.json и локальный сервер. Запуск: node server.mjs. Проверки: node tests/all.test.mjs. Внешние зависимости не нужны. GitHub Actions проверяет и публикует dist через GitHub Pages. Избранное хранится отдельно в браузере каждого пользователя, аналитика не подключена.
