# Квинта. · 2.4.0

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Добавлены шесть видов такта для светлой и тёмной темы: пульс по краям, контрастный фон, полоса такта, дыхание сцены, ударная волна и инверсия. В настройках можно выбрать эффект, отрегулировать интенсивность и посмотреть предпросмотр без звука.

Выбор общий для метронома, репетиции наборов и песен. Для работы эффекта включите «Экран» или «Мерцание экрана». Настройки сохраняются после выхода и обновления; предпочтения разных разделов больше не перезаписывают друг друга.

Уведомление об обновлении использует утверждённый владельцем текст. Остальные накопленные задачи оставлены в очереди.

378 проверок пройдено. В браузере проверены шесть эффектов, обе темы, метроном, репетиция песни и перенос настроек с предыдущей версии через настоящее обновление приложения. Проверка на физических телефонах остаётся за владельцем.
