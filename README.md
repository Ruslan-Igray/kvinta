# Квинта · 1.9

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, аккорды, метроном и композиции с репетицией. После первой загрузки работает без интернета. На iPhone: Safari → Поделиться → На экран Домой.

## Обновление 1.9

- Подсказки уменьшены до 480 px, шрифты сохранены. Длинный текст прокручивается внутри окна. Все завершающие фразы убраны. В настройках подпись «Факты, справка» без числа карточек.
- Исправлена отмена свайпа при передаче захвата жеста от кнопки всей карточке. Свайп влево открывает удаление, дальнейшее движение удаляет. Для набора доступно восстановление.
- В «Порядке частей» тяните за точки захвата справа вверх или вниз, чтобы переместить шаг. Свайп влево по строке удаляет его. Порядок сохраняется в наборе и передаётся по ссылке. С клавиатуры: фокус на захвате, стрелки вверх/вниз.
- Доли аккордов показаны точками: одна точка — одна доля, группы по четыре. Для больших длительностей есть множитель, например •••• ×4 = 16 долей. В репетиции названия частей, аккорды и точки расположены раздельно. На 360×640 и 390×763 проверена сетка 16 карточек без наложений и прокрутки основного экрана.

160 автоматических проверок. Отмена жеста при передаче захвата дочерней кнопкой покрыта проверкой событий. В браузере проверены свайпы, перетаскивание припева наверх, удаление шага, подписи и размеры окон. Реальный сенсорный ввод iPhone отдельно не воспроизводился.

## Исходники

Архив kvinta-github-source.zip: dist, tests, README, package.json и локальный сервер. Запуск: node server.mjs. Проверки: node tests/all.test.mjs. Внешние зависимости не нужны. GitHub Actions проверяет и публикует dist через GitHub Pages. Избранное хранится отдельно в браузере каждого пользователя, аналитика не подключена.
