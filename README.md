# Квинта · 1.11

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, метроном, аккорды и композиции с репетицией. На iPhone: Safari → Поделиться → На экран Домой. Избранное хранится отдельно на устройстве каждого человека.

## Обновление 1.11

- Подборка в редакторе немедленно меняется для выделенного аккорда с учётом гармонии всей композиции и движений по квартам/квинтам. Выделение не меняет тональность или содержимое набора.
- Исправлена вставка перетаскиванием между карточками. Убраны лишние заголовки и инструкции; длинные обозначения помещаются в карточки, нижняя подборка сохраняет высоту при транспонировании.
- Тон и тип аккорда выбираются прокруткой барабанов в редакторе и разделе «Аккорды».
- Полноэкранная партитура плавно прокручивается со скоростью выбранного темпа и заранее начинает переход к следующей части. Касание — пауза/продолжение; двойное — выход.
- Отсчёт — четыре удара одинаковым звуком палочек в темпе композиции для любого размера.
- Экран и фотовспышку можно включить одновременно в настройках репетиции. Камера подключается в отдельном окне и отключается после остановки; если вспышка недоступна, используется экран.
- В избранном свайп вправо открывает обмен набором; влево — удаление с возможностью восстановления.
- Переработаны окна названия/действий и обмена: крупные названия и кнопки, ссылка скрыта под раскрывающейся строкой.
- Новые ссылки компактнее, имеют контроль целостности и сохраняют части, порядок, точное написание аккордов, длительности, темп, размер и повтор. На проверенном наборе из 33 аккордов ссылка сократилась с 1241 до 266 символов. Старые форматы v1/v2/v3 поддерживаются. В окне ошибки доступна проверка обновления без очистки избранного.

179 автоматических проверок. В браузере проверены вставка между карточками, рекомендации по выделению, выбор барабанами, длинные названия на экранах 360×640 и 390×763, двенадцать тональностей без скачков высоты, сохранение из окна действий, обмен свайпом, импорт точной ранее сообщённой ссылки с 33 аккордами, отсчёт, полный экран и пауза.

Физический iPhone и работа его светодиода удалённо не тестировались. Причина ошибки ссылки на конкретном телефоне в актуальном обработчике не воспроизвелась; проверены старый набор и новый компактный обмен.

## Исходники

Архив `kvinta-github-source.zip`: dist, tests, README, package.json и локальный сервер. Запуск: `node server.mjs`. Проверки: `node tests/all.test.mjs`. Внешние зависимости не нужны. GitHub Actions проверяет и публикует dist через GitHub Pages. Аналитика не подключена.
