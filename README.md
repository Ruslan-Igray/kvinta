# Квинта. · 2.3

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Доли рядом с режимами прокрутки, компактная история поиска, плавные свайпы песен и безопасный отступ текущей строки при автопрокрутке. Темп загруженной записи можно настучать во время прослушивания на исходной скорости и сохранить вместе с песней.

В общих настройках добавлена кнопка «Поделиться приложением». Попытка отправки набора сохраняется до перехода в мессенджер, результат учитывается отдельно. Закрытая статистика различает отправку и копирование наборов и самого приложения; доставка сообщения не отслеживается.

348 проверок приложения пройдено. Проверены мобильные размеры 390×844 и 320×568, загрузка локального WAV, применение исходного темпа без изменения скорости прослушивания. Физический iPhone в этой среде недоступен. Автосинхронизация текста с записью отложена до выделенного сервера. Исходники — в kvinta-github-source.zip.
