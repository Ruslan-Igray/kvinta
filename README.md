# Квинта. · 2.1.4

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Компактное окно аккорда с шестью цветами, единым полем долей и просмотром грифа. Метки с прокруткой действий и видимыми значками. Общие настройки песен, настраиваемая панель до пяти кнопок, настоящая фотовспышка через общий с Инструментами контроллер.

Мои песни: нажатие открывает, свайп влево удаляет с возможностью вернуть, вправо — обмен сохранённой версией. Логотип «Пульс медиатора», одинаковые готовые иконки шапок и быстрая обратная связь при переходе.

290 проверок пройдено. Проверены размеры 320×568, 360×640, редактор, сохранение настроек и свайпы. Фотовспышку нужно проверить на физическом телефоне. Исходники — в kvinta-github-source.zip.

Перенос поискового сервера без VPN пока не подключён.
