# Квинта. · 2.1.1

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Поиск AmDm + MyTabs по названию и исполнителю, просмотр песен исполнителя. Исправлены удержание аккорда при прокрутке, вставка элементов в видимую строку, высота экрана. Аккорды не накладываются друг на друга. В шапке — иконки двух режимов.

270 проверок пройдено. Поиск обоих источников проверен на опубликованном сервере. Исходники и подробности в kvinta-github-source.zip.
