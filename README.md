# Квинта. · 2.2.1

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Исправлено управление фотовспышкой в метрономе, наборах и песнях: прогрев камеры, проверка включения светодиода, выбор другой доступной задней камеры, совместимые команды и более заметный импульс. Остановка отменяет запоздавшие команды и освобождает камеру.

Подключение даёт один пробный импульс. Кнопка «Проверить вспышку» даёт ещё три без запуска репетиции. Камера используется без записи и отправки изображения.

326 тестов пройдено. Проверены ошибки команд камеры, задержки, остановка, выбор другой камеры и мобильные окна 390×844 / 320×568. Физические Samsung в этой среде недоступны: светодиод нужно проверить на телефоне. Исходники — в kvinta-github-source.zip.
