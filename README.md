# Квинта · 1.7.1

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, справочник аккордов, метроном и композиции с репетицией. Работает без интернета после первой загрузки. На iPhone: Safari → Поделиться → На экран Домой.

## Исправление 1.7.1

Убраны рамки у кнопок закрытия и «Ещё». Удалена отложенная попытка блокировки поворота; портретная компоновка включается стилями сразу. Системную анимацию iOS веб-приложение отключить не может.

## Обновление 1.7

- Редактор: все 16 аккордов одной части помещаются в рамке 4×4 без прокрутки, включая третий и четвёртый ряды. Проверены 390×763 и 360×640. На малых экранах дополнительные настройки вынесены отдельно, выбранный другой аккорд остаётся доступен для перетаскивания.
- «Темп по звуку»: 24 полосы реагируют на реальный спектр микрофона внутри модального окна. Предварительный BPM появляется после накопления ритма и уточняется до результата на 12-й секунде. Результат применяется вручную, есть ×2/÷2.
- Удержание −/+ ускоряет изменение темпа; отпускание сразу останавливает повтор. Убрано синее выделение при касаниях. Клавиатурный фокус сохранён.
- Исправлено возвращение фокуса на списки тона/типа аккорда, из-за которого на iPhone список мог открываться повторно.
- Общие звуки: Дерево, Щелчок, Тссс, Колокольчик, Треугольник. Переработано восстановление аудио после прерываний и микрофона; добавлена кнопка «Восстановить звук». Синтез на устройстве, загрузка аудиофайлов не требуется.
- При повороте телефона сохраняется портретная компоновка; метроном и тюнер не получают команду остановки. Поддерживаемая системная блокировка ориентации используется по возможности, иначе поворачивается единый портретный холст.
- Нижняя панель: Тюнер → Круг → Метроном → Аккорды → Избранное.
- 313 стартовых карточек: музыкальный факт → отрывок справки → фраза владельца. Все 69 фраз включены. Не более семи карточек за запуск, затем «Стоп, идите занимайтесь.».

146 автоматических проверок. В браузере проверены размещение 16 карточек, удержание темпа, восстановление звука, закрытие списков и продолжение метронома после поворота. Работа с реальным микрофоном iPhone требует проверки на устройстве; универсальное устранение системных сбоев Safari не заявляется.

## Исходники

`kvinta-github-source.zip` содержит dist, tests, README и локальный сервер. Запуск: `node server.mjs`. Проверки: `node tests/all.test.mjs`. Внешние зависимости не нужны. GitHub Actions проверяет сборку и публикует dist через GitHub Pages. Избранное хранится в браузере каждого пользователя. Аналитика пользователей не подключена.
