# Квинта · 1.4

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: круг тональностей, аккорды с аппликатурами и звуком, метроном, тюнер через микрофон и композиции с куплетами/припевами. Светлая/тёмная тема, офлайн после загрузки. На iPhone: Safari → Поделиться → На экран Домой.

## Обновление 1.4

- 28 музыкальных карточек: короткие абзацы, выделения, цветные символы, аккуратные переносы. Без видимых ссылок. Последние восемь подсказок не повторяются; отключение в настройках сохранено.
- Репетиция может играть аккорды гитарным звуком синхронно с метрономом, темпом, размером, длительностями и всеми частями песни. Кнопка «♪ Аккорды» включает и выключает звучание.
- Наборы в избранном удаляются свайпом влево. Короткий свайп открывает кнопку, длинный удаляет при отпускании. Можно восстановить.
- Центрированы названия позиций аккорда.
- Тюнер: спокойный «Обычный» режим ±8 центов и более быстрый «Точный» ±3. Переключение над большой нотой, выбор запоминается. Порог тихого сигнала сохранён. Проверка работы с гитарой на реальном iPhone ещё необходима.

Метроном озвучивает настукивание выбранным тембром и громкостью. Тембр находится в общих настройках. Подключение вспышки — в отдельном окне.

118 автоматических проверок; интерфейс проверен на 390×763 и 360×640.

## Исходники и публикация

`kvinta-github-source.zip` содержит dist, tests и локальный сервер. После распаковки: `node server.mjs` и `node tests/all.test.mjs`. Внешние зависимости не нужны. GitHub Actions запускает проверки и публикует dist через GitHub Pages. Избранное хранится отдельно в браузере каждого пользователя; композициями можно делиться ссылками.
