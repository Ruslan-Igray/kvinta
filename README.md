# Квинта. · 2.3.1

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Исправлены рывки автопрокрутки: дробные смещения сохраняются, равномерный режим движется с постоянной скоростью, старт во время возврата к началу не возвращает прежнюю позицию. Свайп песни ждёт 140 мс и уверенное горизонтальное движение, без начального скачка.

В быстрой панели исправлена иконка метронома. Доли блока меняются вертикальным перетаскиванием, колесом или вводом; рядом видны такты и число аккордов. Справка объясняет режимы прокрутки и путь к темпу записи по тапам.

350 проверок пройдено. Браузер: 390×844 и 320×568; наблюдаемое движение 21 пиксель за 1,13 секунды, без обратных шагов. Физический телефон в среде недоступен. Исходники — в kvinta-github-source.zip.
