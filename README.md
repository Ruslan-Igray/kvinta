# Квинта · 1.13.1

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, метроном, аккорды и композиции с репетицией. На iPhone: Safari → Поделиться → На экран Домой. Избранное хранится на устройстве каждого человека.

## Обновление 1.13.1

Информация и управление отправкой статистики находятся в «Справка → О приложении → Конфиденциальность». В основных настройках нет упоминаний статистики и ссылки на кабинет владельца. Фоновый сбор продолжается с сохранением выбранного пользователем состояния, в том числе после обновления и перезапуска.

Имена, содержимое наборов, сами ссылки и записи микрофона в статистику не передаются. Данные отправляются на собственный сервер Квинты, сводка доступна только владельцу. Подробнее — в разделе конфиденциальности приложения.

192 проверки приложения. Браузером проверены основные настройки без статистики, поиск и открытие конфиденциальности, выключение и сохранение состояния после перезапуска.

## Исходники

В kvinta-github-source.zip: статический dist, тесты, исходники коллектора, схема и миграции без секретов. Запуск: node server.mjs. Проверки: node tests/all.test.mjs. Нужен современный Node 22+. GitHub Actions проверяет приложение и публикует только статические файлы dist.
