# Квинта. · 2.1.2

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Редактор песен: прокрутка основного тона, типа и долей; выбор слова для аккорда или пометки; сохранение цвета и позиции. История десяти запросов, очистка строки, возврат к вариантам песни по заголовку. Кнопка «Песни» в шапке; четыре удара палочками включаются в настройках.

279 проверок пройдено. Исходники и подробности в kvinta-github-source.zip.

Перенос сервера поиска для работы без VPN подготовлен, но пока не подключён.
