# Квинта. · 2.3.2

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Исправлена синхронизация щелчков, долей и света: звук планируется заранее по аудиочасам, отображение ждёт фактического времени вывода. Общий световой ритм для песен, отдельного метронома и наборов. Пауза и смена темпа отменяют будущие щелчки; устаревшие световые события не догоняют воспроизведение.

Проверены четырёхдольный отсчёт, переход к песне, запись и её реальная скорость, буферизация и предварительное прослушивание на 1×. Введённый исходный BPM сохраняется при выходе из поля и закрытии окна.

365 проверок пройдено, включая десятиминутные модели 40/96/137/220 BPM и задержку вывода. Мобильный браузер проверен. Физический динамик и светодиод iPhone не измерены: программно общий момент события не гарантирует нулевую аппаратную задержку камеры.
