# Квинта · 1.6

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер через микрофон, круг тональностей, аккорды с аппликатурами и звуком, метроном и композиции с куплетами/припевами. Светлая/тёмная тема, офлайн после загрузки. На iPhone: Safari → Поделиться → На экран Домой.

## Обновление 1.6

- «Слушать темп»: 12 секунд звука через микрофон, оценка пульса, ×2/÷2 и применение результата. Размер выбирается вручную. Звук обрабатывается на устройстве и не сохраняется.
- Устойчиво настроенная струна подтверждается выбранным звуком приложения, с защитой от повторных сигналов и собственного звука динамика.
- Сначала инструмент, затем готовый строй: гитара 6 струн, бас 4 струны, укулеле, гитара 12 струн. Парные струны показаны с октавами; свой строй поддерживает до 12 струн.
- Обычные окна по центру экрана. Компактные заголовки настроек. Общий выбор Дерево / Щелчок / Тссс и кнопка «Воспроизвести звук», без отдельной настройки рамки.
- «Ещё» в подсказках: не больше пяти карточек за открытие приложения, затем «Урок закончен. Ищи ищи струны.». Полная очередь из 300 карточек без повторов сохранена.

Сохранены стартовый тюнер, избранное справа, проигрывание композиции в репетиции, копирование куплетов/припевов, общий темп и размер, обмен ссылками и два режима точности тюнера. Сбор общей статистики пользователей не подключён.

134 автоматические проверки. Основные экраны проверены на 390×763 и 360×640. Анализ темпа проверен на синтетических ритмах, шумах и моделях микрофона. Реальная работа с песней и гитарой на iPhone проверяется на устройстве владельца.

## Исходники и публикация

`kvinta-github-source.zip` содержит dist, tests и локальный сервер. После распаковки: `node server.mjs` и `node tests/all.test.mjs`. Внешние зависимости не нужны. GitHub Actions запускает проверки и публикует dist через GitHub Pages. Избранное хранится отдельно в браузере каждого пользователя.
