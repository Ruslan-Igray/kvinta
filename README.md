# Квинта · 1.10

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, аккорды, метроном и композиции с репетицией. После первой загрузки работает без интернета. На iPhone: Safari → Поделиться → На экран Домой.

## Обновление 1.10

- Настройки строя тюнера — иконка справа в строке инструмента и строя.
- Настройки репетиции: «Отсчёт» — один такт палочками перед первым аккордом; «На весь экран» — заголовки частей и крупные карточки без остального управления. Отсчёт по умолчанию включён, полный экран — выключен. Выбор запоминается на устройстве.
- На полном экране касание ставит на паузу или продолжает с остановленной доли. Двойное касание возвращает обычный экран без сброса репетиции. Прокрутка списка не считается касанием. Клавиатура: пробел/Enter — пауза, Escape — выход. Текущий аккорд подсвечивается и автоматически попадает в область просмотра. Вход и выход плавные; настройка уменьшения движения учитывается.
- «Проигрыш» добавляется как куплет или припев, копируется, сохраняется и включается в порядок частей.
- Длительность выбранного аккорда — барабан 1–32 долей со щелчками, «1 такт» и «Всем» сохранены. Барабан при открытии показывает текущую длительность.
- У свайпа удаления оставлено только «Удалить», убраны дополнительные инструкции.

168 автоматических проверок. В браузере проверены отсчёт, его отключение, полный экран с тремя типами частей, пауза, продолжение, выход двойным касанием, сохранение воспроизведения при повороте окна, прокрутка долей 4 → 6, иконка настроек строя. Работа на физическом iPhone отдельно не воспроизводилась.

Полный экран занимает доступное окно приложения; не используется системный Fullscreen API. Пауза глушит запланированный звук, продолжение повторяет остановленную долю и оставшуюся часть текущего аккорда, затем следует исходным границам. Выход из полного экрана не останавливает игру. Фон/закрытие приложения и ошибки звука останавливают репетицию.

## Исходники

Архив kvinta-github-source.zip: dist, tests, README, package.json и локальный сервер. Запуск: node server.mjs. Проверки: node tests/all.test.mjs. Внешние зависимости не нужны. GitHub Actions проверяет и публикует dist через GitHub Pages. Избранное хранится отдельно в браузере каждого пользователя, аналитика не подключена.
