# Квинта · 1.15

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, метроном, аккорды и композиции с репетицией. На iPhone: Safari → Поделиться → На экран Домой. Избранное хранится на устройстве каждого человека.

## 1.15 — линия живого звука и распознавание затухания

В квадрате тюнера теперь вертикальная сглаженная осциллограмма из последних 40 мс входного сигнала с привязкой к переходу через ноль; она обновляется даже при неопределённой высоте ноты. Шкала точности расположена отдельно над волной. Появились более заметные плавно движущиеся контуры слушателя, «Жду ноту»; удалены кнопка «Подробнее» и подпись истории. Измерение уровня использует свежий сигнал. Анимации останавливаются вместе с микрофоном и учитывают уменьшение движения. Входные данные обрабатываются локально и не сохраняются. Основа захвата: [Web Audio specification](https://www.w3.org/TR/webaudio/#dom-analysernode-getfloattimedomaindata).

Одна кнопка: «Авто выкл» определяет ближайшую струну по звуку, «Авто вкл» ведёт проход по порядку. После выключения и завершения прохода возвращается определение по звуку. Нажатие струны воспроизводит эталон. Переключатель точности находится в настройках строя.

Воспроизведён дефект YIN на быстро затухающем модельном сигнале: E2 давала null, A2 имела уверенность около .887, D3 около .931. Сравнение периодов компенсирует разницу энергии двух окон, вызванную затуханием, сохраняя проверку периодичности и обертонов. В том же примере все три ноты определяются с точностью лучше одного цента. Не утверждается, что модель совпадает со звуком конкретного iPhone.

Авто допускает пропуск измерения до 180 мс, учитывает только время достоверных устойчивых кадров. Реальная расстройка и более длинный пропуск сбрасывают накопление. Порог тишины при переходе приведён к порогу тихой гитары, чтобы продолжающаяся тихая нота не засчитывала соседние одинаковые струны.

208 автоматических проверок: прежние проверки нот/октав/шума/ресурсов, затухание E/A/D с обертонами на 44.1/48/96 кГц, шум с затуханием, высокие ноты, линия до определения ноты, отсутствие линии от старого звука, пропуски Авто. Физическая проверка iPhone 13 Pro остаётся за владельцем.

## Исходники

В kvinta-github-source.zip — статическое приложение, тесты и исходники коллектора без секретов. GitHub Actions проверяет приложение и публикует только dist. Запуск: node server.mjs. Проверки: node tests/all.test.mjs; Node 22+. Стенд tests/browser/tuner.html не публикуется.
