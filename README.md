# Квинта · 1.3

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: круг тональностей, аккорды с аппликатурами и звуком, метроном, тюнер через микрофон, композиции с куплетами/припевами и репетицией. Светлая/тёмная тема, офлайн после загрузки. На iPhone: Safari → Поделиться → На экран Домой.

## Обновление 1.3

Увеличены номера ладов; добавлена защита от горизонтального режима. Исправлены щелчки при прокрутке, белые импульсы и заполнение карточки в репетиции. Другой аккорд и тональность доступны отдельно в редакторе. Куплеты и припевы можно копировать, переименовывать, переставлять и сохранять/передавать по ссылке вместе с темпом и длительностями. Настукивание звучит выбранным тембром; тембр в общих настройках, подключение вспышки в отдельном окне.

Тюнер лучше отслеживает тихий затухающий звук, не даёт направление при неясной струне или октаве. Эталон звучит три секунды; для прослушивания захват микрофона останавливается. После эталона включите микрофон вручную. Проверка с гитарой на реальном iPhone ещё необходима.

107 автоматических проверок; интерфейс проверен на 390×763 и 360×640.

## Исходники и публикация

`kvinta-github-source.zip` содержит dist, tests и локальный сервер. GitHub Actions распаковывает архив, запускает проверки и публикует dist через GitHub Pages. В архив не входят учётные данные и настройки других площадок. Избранное хранится в браузере каждого пользователя.
