# Квинта. · 2.4.1

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Оптимизирована фотовспышка: короткий импульс 90 мс, ровные интервалы по долям с учётом задержки камеры и без очереди пропущенных ударов. Поддержка по-прежнему проверяется реальным включением при подключении и ручной проверке. На быстром темпе вспышка пропускает доли равномерно; фактическая скорость зависит от камеры и браузера.

Настройки репетиции разделены на «Игра», «Экран и свет» и «Приложение». Общие тема, звук, подсказки, установка, обмен приложением и проверка обновлений доступны прямо из песен. Заголовок, вкладки и «Ок» остаются на месте.

Обновления проверяются раз в минуту, при возвращении в приложение и вручную в настройках. Загрузка не прерывает игру. Применение ждёт остановки звука и микрофона, окончания редактирования, сохранения правок песни и закрытия открытых модальных окон. Другие открытые окна Квинты тоже должны быть готовы. Настройки и выбранный раздел сохраняются.

Для первоначального перехода с 2.4.0 или более ранней версии один раз закройте все окна Квинты и откройте приложение с интернетом: прежний код ещё не содержит нового механизма обновления. Следующие обновления доставляются в открытое приложение и применяются в безопасной паузе.

386 проверок пройдено. В браузере подтверждены загрузка обновления во время работы метронома на 220 BPM и применение только после остановки, сохранение раздела и темпа; меню проверено в обеих темах. Физическая вспышка телефона в этой среде недоступна — владельцу следует проверить результат на своих Android/iPhone.
