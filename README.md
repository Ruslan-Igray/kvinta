# Квинта. · 2.1.3

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Переключатель «Приборы и сцена». Общие шапка, логотип, шрифт и ширина для инструментов и репетиции. Статическая шапка присутствует ещё до запуска кода песни.

Проверено совпадение размеров и координат при 360×640, 390×844 и на ПК. 279 проверок пройдено. Исходники — в kvinta-github-source.zip. Новые варианты логотипа обсуждаются отдельно и не внедрены.

Перенос сервера поиска для работы без VPN пока не подключён.
