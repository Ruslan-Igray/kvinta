# Квинта

Мобильное приложение для гитаристов: круг тональностей, аккорды на грифе, наборы с транспонированием и обменом по ссылке, репетиция, метроном и тюнер.

## Открыть приложение

**https://ruslan-igray.github.io/kvinta/**

Откройте ссылку в браузере телефона или компьютера. Можно отправлять друзьям; установка из магазина не требуется. На телефоне приложение можно добавить на главный экран через меню браузера.

## Исходники и проверки

Полный проект версии 0.16.0 находится в архиве [kvinta-github-source.zip](./kvinta-github-source.zip). После распаковки нужны Node.js 22 или новее и команды:

```sh
npm start
npm test
```

Локальный адрес — http://localhost:4173/. Внешних зависимостей нет. В проект входят 87 проверок музыкальной теории, аппликатур, звука, метронома, тюнера и сохранности наборов.

## Обновление сайта

Замените архив `kvinta-github-source.zip` новой проверенной версией и сохраните изменение в `main`. Процесс [Publish Kvinta to GitHub Pages](../../actions/workflows/pages.yml) распакует проект, выполнит проверки и опубликует только его папку `dist/`. Процесс также можно запустить вручную во вкладке Actions.

Публикация не изменяет файлы репозитория: исходники доступны только для чтения, а отдельное разрешение Pages используется для размещения сайта.

## Данные на устройстве

Избранное, черновики и настройки хранятся в браузере пользователя. Ссылка на набор содержит отдельную копию с темпом, размером и длительностями; другие наборы не передаются.

При переходе на другой адрес сайта избранное не переносится автоматически. Перенести нужные наборы можно ссылками через «Поделиться набором». Очистка данных сайта удаляет локальные данные.

Микрофон включается только кнопкой запуска тюнера. Для офлайн-работы дождитесь надписи «Доступно без интернета» после первой загрузки.
