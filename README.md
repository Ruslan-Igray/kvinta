# Квинта · 1.14

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, метроном, аккорды и композиции с репетицией. На iPhone: Safari → Поделиться → На экран Домой. Избранное хранится на устройстве каждого человека.

## Обновление 1.14 — пробуем новый тюнер

- На основном экране крупная нота, зона настройки, короткий след высоты звука и одна рекомендация. Центы, частота и переключение точности перенесены в «Подробнее».
- После затухания достоверный результат остаётся на четыре секунды с подписью «Последний щипок». Сохранённое показание не запускает звук подтверждения или автопереход.
- Одиночные резкие выбросы не сбрасывают устойчивую ноту. Большой переход подтверждается несколькими согласованными измерениями; настоящая расстройка и смена струны остаются видимыми.
- История ограничена четырьмя секундами и не соединяет пропуски сигнала выдуманной линией. Звук не записывается и не отправляется.

200 автоматических проверок прошли. Браузером проверены синтетические E, отклонения в обе стороны, выбросы, затухание и сохранённый результат, точные измерения, оба режима, обе темы и шесть шагов Авто. Размеры 390×763 и 360×640 — без прокрутки. Это пробное исправление по описанию владельца: работа на физическом iPhone 13 Pro с неподключённой электрогитарой ожидает проверки владельцем.

## Исходники

В kvinta-github-source.zip: статический dist, тесты, исходники коллектора, схема и миграции без секретов. Запуск: node server.mjs. Проверки: node tests/all.test.mjs. Нужен современный Node 22+. GitHub Actions проверяет приложение и публикует только статические файлы dist. Локальный tests/browser/tuner.html работает на искусственных сигналах через audioFactory; он не публикуется в приложении.
