# Квинта. · 2.1.5

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Точки такта в полноэкранной песне скрыты по умолчанию; их можно включить в настройках и добавить в панель до пяти кнопок. Размер текста — 10–28, с сохранением между песнями.

В окне аккорда занятые места над словами приглушены и недоступны, название аккорда проигрывается по нажатию. Короткие стандартные метки в одно слово, собственные подписи сохраняются.

295 проверок пройдено. Оригинальная запись с синхронным текстом и группа нескольких аккордов над словом описаны как предложения, пока без внедрения. Размер песенного плеера пока фиксирован 4/4.

Исходники — в kvinta-github-source.zip.
