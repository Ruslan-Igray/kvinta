# Квинта. · 2.2

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Размер песни выбирается прокруткой рядом с темпом и сохраняется с песней. Метроном использует выбранное число долей, их единицу и акцент такта.

Кнопка наушников открывает запись с телефона: MP3, M4A или WAV до 80 МБ. Нажатия на строки отмечают их вступления. Текст следует времени записи, пауза останавливает и текст, и аудио; перед началом доступны четыре палочки. Можно менять скорость через темп, оригинальная тональность аудио сохраняется при поддержке браузером.

Файл хранится на устройстве. Ссылка передаёт размер и временные отметки без самого файла и его локального идентификатора. Получатель выбирает свою запись. После очистки памяти браузера файл потребуется выбрать повторно. Поиск и скачивание аудио на этом этапе не добавлялись по уточнению владельца.

310 тестов пройдено. Проверены браузерные размеры 390×844 и 320×568, импорт WAV, разметка, сохранение, запуск/пауза, отсчёт и полноэкранное управление. Физический iPhone требует проверки владельцем. Исходники — в kvinta-github-source.zip.
