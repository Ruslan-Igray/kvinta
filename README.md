# Квинта · 1.14.1

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, метроном, аккорды и композиции с репетицией. На iPhone: Safari → Поделиться → На экран Домой. Избранное хранится на устройстве каждого человека.

## Обновление 1.14.1 — живые показания тюнера

- Исправлена ошибка 1.14: распознанные слабые E₂, A₂ и D₃ скрывались из-за умеренной уверенности. Теперь они отображаются и обновляются с подписью «Уточняю ноту». Такие оценки не подтверждают настройку и не запускают Авто.
- Шкала сигнала снова на основном экране. При включённом микрофоне мягко движется фон и видна подпись «Слушаю»; шкала показывает измеренный уровень, в тишине остаётся на нуле. Движение прекращается после остановки.
- Нота плавно меняет акцентный цвет на зелёный по мере приближения к цели, с мягкой контурной подсветкой. Неуверенная оценка не становится полностью зелёной. Уменьшение движения учитывается.
- Текущие оценки отделены от последнего достоверного результата. Пороги распознавания не ослаблены. Запись и передача микрофона отсутствуют.

204 автоматические проверки прошли. В браузере проверены слабые E/A/D, приближение к цели, тишина, остановка, все шесть шагов Авто и обе темы, размеры 390×763 и 360×640 без прокрутки. Проверка использовала искусственный сигнал, без доступа к микрофону. Физическая проверка на iPhone 13 Pro с неподключённой электрогитарой ожидает владельца.

## Исходники

В kvinta-github-source.zip: статический dist, тесты, исходники коллектора, схема и миграции без секретов. Запуск: node server.mjs. Проверки: node tests/all.test.mjs. Нужен современный Node 22+. GitHub Actions проверяет приложение и публикует только статические файлы dist. Локальный tests/browser/tuner.html работает на искусственных сигналах; он не публикуется в приложении.
