# Квинта · 1.5

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер через микрофон, круг тональностей, аккорды с аппликатурами и звуком, метроном и композиции с куплетами/припевами. Светлая/тёмная тема, офлайн после загрузки. На iPhone: Safari → Поделиться → На экран Домой.

## Обновление 1.5

- Единый выбор звука: Дерево, Щелчок, Тссс. Тембр применяется к метрономам, настукиванию, рамке, ползункам и барабанам. Выбор запоминается.
- Стартовый экран — тюнер, микрофон включается кнопкой. Нижняя панель: Тюнер, Круг, Аккорды, Метроном, Избранное. Ссылки на композиции сразу открывают полученный набор.
- 300 карточек с фактами, понятиями и практикой. Все заголовки и тексты уникальны. Перемешанная очередь сохраняется: полный цикл без повторов, затем новая очередь. Отключение подсказок доступно в настройках.

Сохранены гитарное проигрывание композиции в репетиции, копирование куплетов/припевов, общий темп и размер, обмен ссылками, восстановление удалённых наборов и два режима точности тюнера.

126 автоматических проверок. Стартовый экран проверен на 390×763 и 360×640. Реальная настройка гитары через микрофон iPhone проверяется на устройстве владельца.

## Исходники и публикация

`kvinta-github-source.zip` содержит dist, tests и локальный сервер. После распаковки: `node server.mjs` и `node tests/all.test.mjs`. Внешние зависимости не нужны. GitHub Actions запускает проверки и публикует dist через GitHub Pages. Избранное хранится отдельно в браузере каждого пользователя.
