# Квинта · 1.12

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, метроном, аккорды и композиции с репетицией. На iPhone: Safari → Поделиться → На экран Домой. Избранное хранится отдельно на устройстве каждого человека.

## Обновление 1.12

- В редакторе постоянно видны «Основной тон» и «Тип аккорда» с прокруткой, как в разделе «Аккорды». Поле выбранного аккорда остаётся рядом. На небольших экранах только смена тональности открывается отдельно.
- Возвращена подборка семи аккордов выбранной тональности. Выделение карточки в сетке больше не перестраивает рекомендации.
- Исправлена прокрутка полноэкранной партитуры: заголовки идут над аккордами и не накрывают верхнюю строку. Переход к следующей части привязан к устойчивой позиции её заголовка, без обратного перезапуска движения. Длительность перехода учитывает темп и расстояние.
- Повтор длинной партитуры продолжается ниже, без прокрутки назад через все части. Одновременно в представлении не более двух проходов; пройденный проход удаляется с сохранением видимой позиции. Помещающаяся партитура не дублируется.
- В строке над аккордами репетиции доступны «Вся композиция» и отдельные части: куплет, припев, проигрыш. «По кругу» повторяет выбранную область. Выберите её до старта; во время игры сначала нажмите «Стоп».
- Выбор отдельной части применяется к сетке, звучанию и полному экрану. Сохранённые аккорды и порядок композиции сохраняются целиком.
- Улучшено размещение обозначений аккордов с учётом фактической ширины текста и запаса от обрезания.

186 автоматических проверок. Браузерная проверка: 16 карточек и оба поля выбора без прокрутки на 360×640 и 390×763; длинное D♭sus4 помещается; подборка не меняется от выделения; отдельный припев играет по кругу; полный проход 33 аккордов с тремя частями проверен на нескольких кругах, текущая карточка видна, заголовки не перекрывают аккорды. Физический iPhone удалённо не тестировался.

## Исходники

Архив `kvinta-github-source.zip`: dist, tests, README, package.json и локальный сервер. Запуск: `node server.mjs`. Проверки: `node tests/all.test.mjs`. Внешние зависимости не нужны. GitHub Actions проверяет и публикует dist через GitHub Pages. Аналитика не подключена.
