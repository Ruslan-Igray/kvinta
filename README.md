# Квинта. · 2.1

Тюнер, метроном, аккорды, круг тональностей и песни для репетиции.

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

В шапке «Инструменты / Репетиция». Поиск и импорт песен, редактор текста с аккордами и пометками, две прокрутки и короткие ссылки на сохранённые версии. При первом мобильном запуске — предложение установки на экран телефона.

258 проверок пройдено. Исходники и подробности в kvinta-github-source.zip.
