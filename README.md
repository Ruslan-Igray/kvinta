# Квинта · 1.13.2

[Открыть приложение](https://ruslan-igray.github.io/kvinta/)

Мобильное приложение для гитаристов: тюнер, круг тональностей, метроном, аккорды и композиции с репетицией. На iPhone: Safari → Поделиться → На экран Домой. Избранное хранится на устройстве каждого человека.

## Обновление 1.13.2

Исправлена загрузка закрытого кабинета статистики. Вошедший владелец получает подписанный ключ чтения на 2 минуты, привязанный к адресу кабинета, периоду и источнику. Браузер загружает сводку напрямую из коллектора; долгосрочные ключи остаются только на серверах. Показатели обновляются раз в 30 секунд и при возвращении во вкладку.

События обмена отправляются сразу. При сворачивании приложения и закрытии страницы дополнительно выполняется попытка отправить накопленные события. Сохранённый выбор отключения статистики не сбрасывается. Информация и выключатель остаются в «Справка → О приложении → Конфиденциальность».

Обычная ссылка на приложение учитывается как запуск. «Обмен наборами» считает отправку и копирование конкретного набора кнопками Квинты; пересылка готового сообщения за пределами приложения не видна. Установки оцениваются по первым запускам с иконки.

194 проверки приложения и 2 проверки защиты кабинета. На рабочих серверах проверена вся цепочка: сервисный вход в закрытый кабинет, выдача временного ключа и чтение настоящей сводки с правильным CORS. Проверочные события в production не создавались.

## Исходники

В kvinta-github-source.zip: статический dist, тесты, исходники коллектора, схема и миграции без секретов. Запуск: node server.mjs. Проверки: node tests/all.test.mjs. Нужен современный Node 22+. GitHub Actions проверяет приложение и публикует только статические файлы dist.
